* Permissions system – attach to licenses and artifact queries 
* Interference & training guardrails – prevent non-permitted inferences 
* License audit – legal review, are the properties useful? 

## Scheduling 
* Inference & training share single scheduling system 
* OpenCue/Deadline Scheduling 
* Environment support – Conda specifically 

## Frontends 
* DCC Plugins - including abstraction & realtime processors
* GUI unification (ingest, train, track & trace – in one place) 
* Train Track & Conductor release 
* Web REST Interface 

## Assets 
* Mesh assets – test examples with Vulcan 
* Values & labelling improvement 
* Correlated aggregate & collection datasets – custom iterators 
* OpenAssetIO support 

## Code Quality 
* Testing expansion – more testing, better VFX specific examples 
* Optimisation – training times, load/reset thrashing 
* Refactoring – moving code folders, naming, cleanup
