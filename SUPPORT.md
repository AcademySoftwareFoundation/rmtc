# Getting Help

There are a few ways to connect with the RMTC project:

* [Issues](https://github.com/AcademySoftwareFoundation/rmtc/issues)
* [Slack](https://academysoftwarefdn.slack.com/archives/C09FP5KUUP4)
* [Wiki](https://lf-aswf.atlassian.net/wiki)

## How to Ask for Help

If you have trouble installing, building, or using RMTC, but there's not yet reason to suspect you've encountered a genuine bug,
start by posting a question to the mailing list or Slack channel. This is the place for question such has "How do I...".

## How to report a bug or request an enhancement

RMTC manages bug and enhancement using it's [Issues](https://github.com/AcademySoftwareFoundation/rmtc/issues). The issue template will guide you on making an effective report.

## How to report a security vulnerability

If you think you've found a potential vulnerability in RMTC, please contact the project
email security@PROJECT DOMAIN to responsibly disclose it.

## Contributing a fix

Please refer to [CONTRIBUTING.md](CONTRIBUTING.md) to make a project contribution.
